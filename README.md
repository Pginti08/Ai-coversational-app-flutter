# Fashion OS - AI Conversational Agent

A Flutter-based fashion application with AI-powered conversational features.

## Description

Fashion OS (formerly Vousvous) is a mobile application that combines fashion e-commerce with AI conversational capabilities, providing users with an interactive and personalized shopping experience.

## Features

- AI-powered conversational interface
- Real-time chat and messaging
- Image browsing and carousel views
- Video player integration
- Push notifications (Firebase)
- Social sharing capabilities
- Payment gateway integration (Razorpay)
- Photo gallery access
- Deep linking support
- Version update management

## Tech Stack

- **Framework:** Flutter 3.5.0+
- **Language:** Dart
- **State Management:** GetX
- **Backend Communication:** Dio, Socket.IO
- **Firebase Services:** Cloud Messaging, Crashlytics
- **UI Components:** Custom animations, shimmer effects, gradient designs
- **Media:** Video player, image cropper, photo viewer

## Getting Started

### Prerequisites

- Flutter SDK (^3.5.0)
- Dart SDK
- Android Studio / Xcode for mobile development

### Installation

1. Clone the repository
```bash
git clone git@github.com:Pginti08/Ai-coversational-agent.git
cd Ai-coversational-agent
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```

## Configuration

Make sure to configure:
- Firebase credentials (`google-services.json` for Android, `GoogleService-Info.plist` for iOS)
- API endpoints and environment variables
- Payment gateway credentials (Razorpay)
